全球100家 >$1B 顶级机构监管底稿 (13F / 13D / CCASS) 视觉化引擎

核心工程逻辑：如何让 Agent 自动生成带时间戳与官方溯源的“小红书图卡”？

每一张卡片强制绑定 4 个物理确权字段：① 监管披露精确日期 (Filing Date)；② 持仓截面报告期 (Report Period)；③ 官方监管源名称 (SEC EDGAR / HKEX CCASS)；④ 原始归档文件直达链接 (Source URL)。

01. 监管嗅探 Agent

7×24轮询 SEC EDGAR (13F/13D)、港交所 CCASS 席位、日本 EDINET，提取精确到日的 Filing Date 与归档号。

02. 量化差分引擎 (Python)

剔除股价涨跌干扰，只算真实股数变动 (ΔShares)；自动剥离 Citadel 等做市商的 Put/Call 期权对冲噪音。

03. 视觉编译 Agent

在封面顶部与卡片底部显式烙印「报告期」与「官方披露时间戳」，一眼辨别数据新鲜度。

04. 原始底稿一键穿透

点击弹窗底部的「查验官方原始底稿」，直接跳转美国证监会 sec.gov 或港交所披露易对应文件页。
